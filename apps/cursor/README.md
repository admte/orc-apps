# cursor

Installs Cursor's command-line agent. With an API key, it checks at start that the key signs in;
the key is not kept on the machine.

- `cursor_api_key` (optional): Cursor API key to check at start; not saved on the machine

Runs on Linux (amd64, arm64), macOS (amd64, arm64) and Windows (amd64, arm64).
