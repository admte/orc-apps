# claude

Installs Claude Code, Anthropic's coding agent, on the machine. Give it an API key and Claude
Code uses it straight away; leave it out and Claude Code waits for a browser sign-in with your
Claude subscription.

- `anthropic_api_key` (optional): Anthropic API key for Claude Code to use

Runs on Linux (amd64, arm64), macOS (amd64, arm64) and Windows (amd64, arm64).
