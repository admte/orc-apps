# gcloud

Installs the Google Cloud CLI so scripts and people on the machine can work with Google Cloud.
Give it a service account key and the CLI is signed in as that account; leave it out and the CLI
is installed ready for you to sign in.

- `service_account_key` (optional): Google Cloud service account key, in JSON

Runs on Linux (amd64, arm64), macOS (amd64, arm64) and Windows (amd64).
