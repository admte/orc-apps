# aws

Installs the AWS CLI v2 so scripts and people on the machine can work with AWS. Give it an
access key and the CLI's default profile is signed in; leave the keys out and the CLI is
installed ready for you to configure.

- `aws_access_key_id` (optional): AWS access key ID; give it together with the secret key
- `aws_secret_access_key` (optional): AWS secret access key; give it together with the key ID

Runs on Linux (amd64, arm64), macOS (amd64, arm64) and Windows (amd64).
