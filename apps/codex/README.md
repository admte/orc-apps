# codex

Installs OpenAI's Codex CLI, a coding agent for the terminal, on the machine. Give it an API key
and Codex is signed in; leave it out and Codex waits for a browser sign-in with your ChatGPT
account.

- `openai_api_key` (optional): OpenAI API key to sign Codex in with

Runs on Linux (amd64, arm64), macOS (amd64, arm64) and Windows (amd64, arm64).
